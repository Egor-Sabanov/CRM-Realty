# FORMA Realty CRM

CRM-панель агентства недвижимости: каталог объектов, клиентские обращения, этапы сделки и история контактов.

## Возможности
- Обзор показателей, последних обращений и новых объектов.
- Каталог: поиск, фильтр статуса, создание карточек и обновление статусов.
- Обращения: поиск, этапы, назначенные сотрудники, связанные объекты, заметки и история активности.
- Вход по учетным данным из переменных окружения.
- Демонстрационное наполнение с вымышленными контактами.

## Технологии
Next.js 16, React 19, TypeScript, PostgreSQL, Prisma 7, CSS Modules.

## Локальный запуск
Требуются Node.js 24 и PostgreSQL.
1. Установить пакеты: npm install.
2. Скопировать .env.example в .env и указать DATABASE_URL, SESSION_SECRET, ADMIN_EMAIL и ADMIN_PASSWORD.
3. Применить схему: npx prisma migrate deploy.
4. Загрузить демо-записи: npm run db:seed.
5. Запустить npm run dev и открыть http://localhost:3000.
6. Войти с парой ADMIN_EMAIL / ADMIN_PASSWORD из локального .env.

Для новых изменений схемы используйте npx prisma migrate dev --name descriptive_name.

## Размещение
Добавьте такие же переменные в настройки хостинга и PostgreSQL. Build запускает генерацию Prisma Client. Примените миграции командой npx prisma migrate deploy и выполните seed один раз. Локальный .env не добавляйте в Git.
